推荐流程

  1. 安装 Node.js（Windows 勾选 Add to PATH；macOS 用官网 pkg），完成后重启本客户端。
  2. 安装并启动 比特浏览器，确认本地 API 为 http://127.0.0.1:54345。
  3. 选择部署目录，点击 一键部署最新。
  4. 浏览器打开 http://127.0.0.1:8400 使用客服端。
